## SOP Assistant

The chat button in the corner opens the SOP Assistant. It answers questions from the published SOPs and cites which ones it used.

It only searches published SOPs, and only the ones the person asking is allowed to see. A draft, an archived SOP, or a SOP in a group someone cannot read will not show up in their answers. It does not read images, so anything that only appears in a picture is invisible to it.

If it cannot find a SOP that is published, an admin can rebuild its search under Settings, Maintenance, Re-index Search Database.

## Generating a flowchart

On a published SOP, the menu has Generate flowchart, which drafts a process map from the steps. It opens in the diagram editor with a banner listing what the AI assumed. Someone has to review it before saving; roughly right is the expectation, not perfect.

It takes up to four minutes. You need to be able to read the SOP and create diagrams in its groups. SOPs over 40 steps get a warning, because the charts get hard to read.

## The glossary

Admins keep a list of terms and definitions under Settings, Definitions. When Scan SOPs on save is on, a SOP picks up the terms it uses the next time it is saved, and readers can see those definitions on the SOP.

A published SOP keeps the definitions it had when it was published. Editing a definition changes drafts right away, but a published SOP only picks it up when it is published again.

The scan is off right now while the list is being filled in. Until it is on, no SOP shows a definition list.
