---
title: "Change requests"
description: "Asking for a change to a published SOP, and resolving one."
---

A change request is how someone asks for a published SOP to be changed. The Request Changes button is on published SOPs, for anyone who can edit that SOP.

Viewers cannot file one. If a Viewer has a change in mind, they need to pass it to someone in the group who can edit, or ask for a higher role.

## Filing

The dialog asks for a reason and lets you leave comments on individual steps. Filing it starts a working copy of the SOP and tells the owner and the group's approvers.

## Resolving

There are three ways a change request ends:

- Mark as Done. Someone makes the change in the working copy and clicks Mark as Done on the request. That clears the request and notes it in the change log. It does not publish anything or notify anyone; the copy still needs to go through review.
- Publish. When the working copy is approved and published, the person who filed the request is told it went live.
- Decline. An approver declines it with a reason. The filer is told, the working copy is discarded, and the published SOP does not change.

Only approvers of the SOP's own groups can decline a change request. Being an approver somewhere else is not enough.
