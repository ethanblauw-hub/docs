## Baselines

A baseline is a snapshot of the schedule to compare against later. Managers and above see Set baseline and Baseline on on the Tickets view.

A manager's baseline is the shop baseline, and everyone sees it. An admin's baseline is private to them and is not shown to the shop.

With Baseline on, each ticket shows a faint bar where it sat in the baseline, so a slip shows as the gap between the two.

## Milestones

Milestones are dated markers on the Resource and Tickets views, for things like a job's ship date. The Milestone button adds one with a label, a date and a color.

Who can add one depends on how far it reaches:

| Scope | Who |
| --- | --- |
| This line | Lead and up |
| Location | Manager and up |
| Org-wide | Admin |

The same dialog edits and removes them, and a change asks for a reason.

## What-if

Managers and above can press What-if on Resource or Tickets to try changes without saving them. A banner says What-if sandbox, and nothing done in it is saved.

Discard throws the changes away. Commit saves them, and they are recorded in each ticket's history the same as any other edit.
