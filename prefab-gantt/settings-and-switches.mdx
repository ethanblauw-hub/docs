Almost every setting in the app is per browser. It follows the computer, not the person, so a shared shop-floor machine keeps whatever the last person chose. The exceptions are the Status Colors page and the Stale flags toggle on the queues, which are shop-wide.

## The Tweaks panel

The sliders icon in the header opens Tweaks. Reset puts everything back to the defaults.

| Setting | Default |
| --- | --- |
| Theme | Light |
| Density | Regular (ultra, dense, compact, regular, comfortable) |
| Bar height | Regular |
| Date order | Month, day, year |
| Month as a name (Oct, not 10) | On |
| Hide the current year | Off |
| Zoom | Day (or week, month, or a column width) |
| Hour number size | 16 px |
| Hour numbers | Decimal (or whole) |
| Bar color | Schedule (or status, job, PM) |
| Material arrival dates | On |
| Rolling charts value axis | Auto (or capped) |
| Show presence heads | On |
| Status colors fallback | Distinct (or ramp) |

The Tickets table's columns are shown and hidden from Tweaks too.

## Experimental features

The bottom of Tweaks lists the feature switches. Like the rest of Tweaks, they are per browser, so turning one off does not turn it off for anyone else.

| Switch | Default | What it does |
| --- | --- | --- |
| Resource leveling assist | On | The Level button on Resource |
| Editable milestones | On | The Milestone button. Off leaves markers showing but read-only |
| Critical path | On | The Critical path button |
| What-if sandbox | On | The What-if button for managers |
| Shop leads edit on Tickets | On | Lets leads edit three fields on the Tickets grid. Off makes the grid manager only |
| Report browser | Off | Replaces most of the Analytics page with the report builder |
| Display-board mode | Off | Not built yet, shown greyed out |

These are the defaults in a fresh browser. Someone who changed a switch keeps their own setting.
